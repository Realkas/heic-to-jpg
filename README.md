# HEIC → JPG Converter

Безкоштовний, повністю локальний конвертер HEIC / HEIF фотографій у JPG прямо у браузері. **Жодного завантаження на сервер — усе відбувається на вашому пристрої.**

---

## Можливості

- 📂 **Три способи додавання файлів**: drag & drop, вибір файлів, вибір цілої папки
- 🔄 **Паралельна конвертація** — до 2 файлів одночасно, черга обробляється автоматично
- 🗜️ **Налаштування якості** JPG (50–100%)
- 📐 **Resize** з дотриманням пропорцій (Contain)
- 📦 **ZIP-архів** зі збереженням структури папок
- 🌙 **Темна / світла тема** зі збереженням у localStorage
- 🔒 **100% приватно** — файли не залишають ваш браузер
- 🇺🇦 Інтерфейс українською мовою

## Як це працює

1. **Завантаження**: Файли читаються через File API або FileSystem Access API (drag & drop).
2. **Валідація**: Перевіряється розширення файлу (`.heic`, `.heif`). MIME-тип ігнорується, бо Windows часто не передає коректний MIME для HEIC.
3. **Конвертація**: Бібліотека `heic-to` декодує HEIC/HEIF за допомогою WASM та конвертує у JPEG Blob. Якщо заданий resize — виконується через Canvas API.
4. **Завантаження**: Один файл — прямий download. Кілька — ZIP через JSZip.

Усі операції відбуваються в браузері. Жодних мережевих запитів із вашими фото.

## Відомі обмеження

- **Вибір папки** через кнопку «Вибрати папку» залежить від підтримки атрибута `webkitdirectory`. Найкраще підтримується в **Chrome** та **Edge**. У Firefox може не працювати або поводитися інакше.
- **Drag & drop папки** з рекурсивним читанням вкладених підпапок потребує FileSystem API (`webkitGetAsEntry`) — доступний у Chrome / Edge / Safari.
- **Великі файли**: HEIC у розрахунку 50+ МБ можуть потребувати значного часу та пам'яті. Рекомендується не закривати вкладку до завершення конвертації.
- **Ліміт браузера**: Для дуже великої кількості файлів (300+) відкрийте підтвердження і дочекайтесь завершення черги.
- **EXIF**: Видалення метаданих EXIF відбувається автоматично в процесі конвертації (JPEG, отриманий через Canvas, не містить оригінального EXIF).

## Поради

- Для найкращої продуктивності використовуйте **Chrome** або **Edge** останньої версії.
- При конвертації великої кількості файлів (100+) **не закривайте вкладку** — процес виконується в основному потоці браузера.
- Якщо файл помічено як «Помилка», натисніть **«Повторити помилкові»** — іноді це допомагає при тимчасових збоях.

  main.tsx             # Точка входу
  index.css            # Глобальні стилі
